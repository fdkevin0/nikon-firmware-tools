# Nikon Body-Lens Serial Communication Protocol

## Overview & Background
This folder preserves historical technical records investigating the electrical serial communication protocol and pinouts between **Nikon F-mount camera bodies and lenses**.

The original research was published by **Gazalou** on [NikonPassion](http://www.nikonpassion.com/). Because the original articles went offline and associated diagrams were lost on the Wayback Machine, community user **ubmtdc** supplied complete PDF captures and English translations.

## File Manifest

1. **Protocol Analysis Documents (PDF)**:
   - [Interpretation des signaux boitier-objectif 1.pdf](Interpretation%20des%20signaux%20boitier-objectif%201.pdf): Part 1 of the original French article by Gazalou.
   - [Interpretation des signaux boitier-objectif 2.pdf](Interpretation%20des%20signaux%20boitier-objectif%202.pdf): Part 2 of the original French article by Gazalou.
   - [Body-Lens signal interpretation 1 - Translated.pdf](Body-Lens%20signal%20interpretation%201%20-%20Translated.pdf): Part 1 English translation.
   - [Body-Lens signal interpretation 2 - Translated.pdf](Body-Lens%20signal%20interpretation%202%20-%20Translated.pdf): Part 2 English translation.

2. **Pinouts & Implementation Code**:
   - [pins.txt](pins.txt): Nikon lens mount pinout definitions compiled by Joseph Wisniewski.
   - [orig.translated.c](orig.translated.c): Early C prototype written by Gazalou emulating a Nikon lens with a PIC microcontroller (French comments translated into English).

## 协议编号定位

[protocol_code_locations.csv](indexes/protocol_code_locations.csv) 记录明确写作 Operation／Property／Event／Response Code 的文本行，附 PDF 路径和页码。

此索引仅供导航，可能漏掉跨行、图片或其他排版的定义。相同编号可能属于不同命名空间，不能仅凭数字合并。查到编号后，应回到 PDF 查看完整定义、合法取值、当前模式及错误条件。
